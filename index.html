ตั้งค่าระบบ & LINE Token (Admin Panel)

ระบุ Web App URL ที่ได้จากการ Deploy ใน Google Apps Script เพื่อให้หน้าเว็บบน GitHub เชื่อมต่อ Google Drive & Sheets จริง

เมื่อเปิดเว็บบน GitHub Pages ข้อมูลและไฟล์จะถูกส่งไปเก็บใน Google Drive และ Google Sheets ของคุณผ่าน API นี้โดยอัตโนมัติ

ใส่ URL ลิงก์รูปภาพโลโก้โรงเรียน (เช่น PNG หรือ SVG) เพื่อแสดงบน Sidebar, Header และ Banner หน้าแรก

ปรับแต่งการแสดงผล / ซ่อนส่วนต่างๆ ในเว็บ (Section Visibility Controls)
